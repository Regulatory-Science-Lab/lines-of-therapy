# Python Scripts

This directory contains scripts for BERT model training, application, and evaluation across tumour-specific and merged cohorts.

- common.py – Shared functions for data preparation, model evaluation, and bootstrapping.
- train_bert.py – Trains and optimizes BERT models using training data.
- apply_bert.py – Applies trained BERT models to evaluation data.
- evaluate.py – Calculates performance metrics, confidence intervals, and relative changes.
- cohorts.py – Constructs tumour-specific and merged analysis cohorts.
- pipeline.py – Automates cohort construction, model training, evaluation, and table generation.
- __init__.py – Defines the Python package.
