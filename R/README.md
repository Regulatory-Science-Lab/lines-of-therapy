# R Scripts

This directory contains scripts for applying and evaluating the rule-based cyclic algorithm.

- cyclic_algorithm.R – Assigns lines of therapy based on the cyclic algorithm's medication history and time-gap rules.
- evaluate_cyclic.R – Evaluates cyclic algorithm performance using accuracy, weighted F1, and patient-level bootstrapping.
- run_cyclic.R – Runs the cyclic algorithm on a prepared cohort and exports medication-level predictions.
